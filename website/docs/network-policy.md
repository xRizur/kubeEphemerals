# Network Policy (Isolation)

The operator can create a **deny-all NetworkPolicy** in each ephemeral environment namespace so that pods in that namespace cannot receive or send traffic to/from other namespaces. This is controlled by the `spec.isolation` field on EphemeralEnv.

## When it applies

- **`spec.isolation: true`** (default) – The operator creates a NetworkPolicy named `deny-all` in the environment namespace (`env-<name>`).
- **`spec.isolation: false`** – No NetworkPolicy is created; pods can communicate with other namespaces as allowed by cluster policies.

## What the policy does

The policy:

- **PodSelector:** empty (selects all pods in the namespace).
- **PolicyTypes:** `Ingress`, `Egress`.
- **Ingress:** empty → no ingress allowed.
- **Egress:** empty → no egress allowed.

So all traffic to/from pods in the namespace is denied unless other NetworkPolicies in the same namespace allow it. Typical use: keep ephemeral envs isolated from each other and from shared services unless you explicitly allow them.

## Example (generated by operator)

The operator creates something equivalent to:

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: deny-all
  namespace: env-pr-123-demo
  labels:
    app.kubernetes.io/managed-by: ephemeral-operator
spec:
  podSelector: {}
  policyTypes:
    - Ingress
    - Egress
  ingress: []
  egress: []
```

## Status condition

When isolation is enabled and the policy is applied, the EphemeralEnv status gets a condition:

- **Type:** `NetworkPolicyApplied`
- **Status:** `True`
- **Reason:** `NetworkPolicyCreated`
- **Message:** `Deny-all NetworkPolicy has been applied`

## Allowing specific traffic

If you need to allow ingress (e.g. from the Gateway) or egress (e.g. to a registry or API), you can add **additional** NetworkPolicies in the same namespace that allow those flows. The operator only creates the single deny-all policy; it does not remove or merge with other policies you add.

## Cleanup

When the EphemeralEnv is deleted or expires, the namespace is deleted, so the NetworkPolicy is removed with it.
